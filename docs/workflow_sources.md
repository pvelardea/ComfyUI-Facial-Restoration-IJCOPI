# Provenance of ComfyUI workflows

Original source: [GusdeJAR/ComfyUI-Upscaling-Inpainting](https://github.com/GusdeJAR/ComfyUI-Upscaling-Inpainting), pinned to commit `c8c76c854f68c27df79d4f29008f00a0b061fc08`.

The file [`../workflows/upstream_manifest.csv`](../workflows/upstream_manifest.csv) stores the six names and original Git blob SHA-1 values at that revision. This prepared bundle contains six sanitised JSON copies. Their unmodified source blobs were verified against `upstream_manifest.csv`, and the included copies are fingerprinted in `prepared_manifest.csv`. No explicit redistribution licence was identified; the repository should remain private until permission from the upstream author is confirmed.

Workflow graphs require local input paths, installed models, third-party nodes and controlled seed settings. The historical stochastic execution state should not be inferred solely from the exported JSON.
